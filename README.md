# 🛡️ Suraksha Setu

A safety-focused Android application designed to provide quick access to emergency assistance, location sharing, and essential safety features for users.

---

## 📌 Project Overview

Suraksha Setu is an Android application developed to enhance personal safety by offering emergency support features. The application is designed to provide users with quick assistance during critical situations.

---

## ✨ Features

- 🚨 Emergency assistance
- 📍 Location sharing
- 📞 Emergency contact support
- 📱 User-friendly interface
- 🔐 Secure authentication
- ☁ Firebase integration

---

## 🛠 Technologies Used

- Kotlin
- Android Studio
- Firebase
- XML
- Git & GitHub
